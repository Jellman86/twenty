# Workbench design

The first dashboard helps a single researcher understand contribution arithmetic and the path to trustworthy evidence. It has no simulated account balance or decorative performance metrics.

Palette: harbour navy `#19374d`, research blue `#3565aa`, hypothesis violet `#7653a3`, slate text `#586b7b`, cloud background `#f1f5f8`, white paper `#ffffff`. A fixed navy workspace rail anchors a restrained light dashboard. Georgia italic is reserved for the research thesis; system sans serves UI and system monospace identifies measured values. No external font requests.

The distinctive element is the contribution chart, where the plain deposit line remains visible against the hypothetical growth path. The target calculation states the required return rather than suggesting an achievable target. The skill's generic operations landing-page and trial CTA suggestions were rejected: this is a research instrument, not a marketing page. Accessible yearly figures accompany the chart; labels, focus outlines, reduced motion and mobile reflow are required.
