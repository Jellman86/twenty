# Raw plan preparation validation

This checkpoint adds a bounded metadata-only service builder and a workbench review form. It implements the existing raw declaration protocol; no strategy, price/FX accounting, execution or candidate-selection rule changes. Core is unchanged. Research identity changes, so previously frozen unspent declarations retain their historical restrictions; completed original artifacts remain inspectable.

## Effects and limitations

Preparation freezes an explicit month-end UTC grid and all supplied execution fields. Hashes and provenance remain assertions until admission; preparation deliberately neither reads nor validates original inputs. Count/quota checks are under the shared store gate, include final-publication headroom, and preserve exact retries. Plan bytes have no new protocol version, random id or timestamp. No study reservation or final authority is created.

The UI uses editable example costs, requires review, displays the returned frozen policy/hash/dates, clears a preview after input changes, and copies the hash into a separate registration form. It does not author session/action source files or turn report inspection into paper integration. A local browser fixture intercepts writes; it must not be represented as a genuine-input or production experiment.

Big Pickle's two preceding review requests failed at its provider usage limit before inspection. No independent design or implementation verdict is claimed for this checkpoint. The browser rehearsal at `raw-plan-ui-r3-20261027` passes desktop/390px checks: malformed calendar JSON, explicit financial review, server refusal/retry, frozen hash/policy preview, edited-preview invalidation and separate exact-hash registration with no automatic start. It uses intercepted authored replies in an isolated context, with zero page errors/production writes. The initial browser harness failed because a placeholder replacement modified bundled JavaScript; ordering the replacements corrected that harness defect. Visual inspection then caught inherited global form-grid and checkbox widths; scoped layout rules corrected them and the fresh r3 rehearsal passed. T3 preview reports missing host libraries, so the existing authenticated shared fallback was used.

Python (45 tests), Ruff, Svelte check/build (zero errors/warnings), scientific boundary and secret checks pass. The full .NET run and exact-source CI are pending at this commit; deployment acceptance is not yet claimed.
